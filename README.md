## Why Type Piano exists

Built for immediate playing rather than account setup, lesson funnels, or a browser tab. Type Piano connects three input paths to one native performance state and one realtime audio engine, so velocity, sustain, held notes, and visible key feedback agree.

> **Free product boundary:** The Community Edition is the complete product. There is no optional tier, activation path, or feature gate.

### The fastest route from a desk to an expressive piano sound.

Type Piano is small in workflow and serious in implementation: native input, shared performance state, a dedicated realtime synth, and a source-attested sample bank work as one instrument.

### Three inputs, one performance model

Play from the computer keyboard, a native MIDI input, or the full on-screen A0-C8 keyboard. Every path feeds the same note ownership, velocity, sustain, and key-state logic.

### Four technically distinct instruments

Choose streamed Studio Grand or Felt Room sample voices, a velocity-responsive FM Classic EP, or the additive Glass Piano instead of disguising one patch behind four names.

### Expressive local audio

The realtime engine supports velocity layers, sustain, release behavior, resonance, pedal samples, device-rate playback, and bounded sample streaming without loading the whole piano library into memory.

### Start playing without a MIDI controller

- The computer keyboard becomes a compact two-row performance layout with octave movement, velocity control, and temporary sustain.
- Pointer input covers the full 88-key visual keyboard and supports glissando instead of reducing the screen to isolated buttons.
- Live key states show held and sustained notes so the display follows the performance rather than decorating it.

### Connect a controller when touch matters

- Native MIDI input carries note velocity and sustain-pedal messages into the same engine used by the computer and screen keyboards.
- Stable input ownership prevents one input source from silencing a note that another source is still holding.
- Device state and recoverable connection notices remain visible instead of silently dropping the performance path.

### A piano bank designed for streaming

- Studio Grand and Felt Room use a verified Salamander Grand Piano V3 bank with velocity, release, resonance, and pedal material.
- Samples are discovered and streamed through bounded voices; the complete bank is not copied into process memory at launch.
- Every release package must preserve the pinned attribution notice and canonical Creative Commons legal text alongside the bank.

### The complete application is free

- All four instruments, all three input methods, the full 88-key range, themes, language choices, and settings persistence are included.
- There is no separate edition, subscription, checkout, activation key, account requirement, or feature gate.
- Linux is the current public package channel; other platform packages are not advertised until their native acceptance evidence passes.

## Frequently asked questions

<details>
<summary><strong>Is the complete Type Piano application free?</strong></summary>

Yes. Community Edition is the complete application: all four instruments, all three input methods, the full 88-key range, sustain, themes, languages, scaling, and settings persistence are included. There is no separate edition, subscription, checkout, account, activation key, or feature gate.

</details>

<details>
<summary><strong>Can I play Type Piano with a computer keyboard?</strong></summary>

Yes. The typing layout provides a compact playable range with octave movement, selectable velocity, and Space as temporary sustain. The on-screen keyboard also supports direct pointer playing and glissando across the full A0-C8 display.

</details>

<details>
<summary><strong>Does Type Piano support a MIDI keyboard and sustain pedal?</strong></summary>

Yes. Type Piano reads native system MIDI input, note velocity, and sustain-pedal CC64 messages. The controller must first be visible to the operating system; device availability and driver behavior still depend on the host setup.

</details>

<details>
<summary><strong>What is the difference between the four instruments?</strong></summary>

Studio Grand and Felt Room stream two presentations of the verified piano sample bank. Classic EP is a velocity-responsive FM electric piano, while Glass Piano is an additive synthesized voice. They are distinct engines, not four labels on one preset.

</details>

<details>
<summary><strong>Which acoustic-piano samples does Type Piano use?</strong></summary>

The sampled voices use Salamander Grand Piano V3 recordings by Alexander Holm under CC BY 3.0. Packages must include the pinned attribution notice and legal text, and the bank is staged through an integrity and provenance gate.

</details>

<details>
<summary><strong>Does playing Type Piano require an internet connection or account?</strong></summary>

No account or cloud performance service is required. Key events, MIDI messages, audio rendering, sample streaming, and interface preferences stay in the local desktop workflow.

</details>
